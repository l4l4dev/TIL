iPhone Duo 向けに、手持ちの本を読むための個人のアプリ [Tanabako](https://apps.apple.com/jp/app/tanabako/id6830099962) を作りました。2026 年 11 月 6 日に、日本の App Store で配信が始まりました。実装からストアへの提出までを AI に任せ、私は決めることと最後の確認だけをしました。開発は数日、App Store に出す作業そのものは実質 1 日でした。

## Claude Code が作って記録し、私は選んで了承した

分担は次のようにしました。

- Claude Code: コードと UI テストを書き、タスクと決めたことの記録、手順の文書を書く。コードは作業用のブランチから PR にして、Codex のレビューを通してからマージする
- Claude in Chrome: App Store Connect の画面に、製品ページの文言、スクリーンショット、価格、年齢制限の回答などを入れる
- 私: 案から選ぶ、回答を了承する、自分のアカウントでしか操作できないところを操作する、最後に確かめる

コードを PR にして Codex のレビューを通すことも、決めたことの記録の 1 つとして残しました。

製品ページの文言は、Claude Code が A/B/C の 3 案を出し、私が B を選びました。審査の担当者への連絡先と、本人として答える申告は、私が自分で入れました。

## ストア側の質問は、コードを読めば答えられるものが多かった

App Store Connect で答える項目には、アプリの作りを調べれば答えが決まるものがありました。

App のプライバシー (データを集めるかどうか) は、Claude Code がコードとプライバシーマニフェストを調べてから答えました。Tanabako が外と通信するのは、利用者が自分でつなぐ Dropbox だけです。Wi-Fi で本を送る機能は、端末の中に `NWListener` で HTTP サーバーを立て、同じ LAN のブラウザから受け取るだけでした。開発者に届くデータがないので、私が了承して「データを収集しない」と答えました。

スクリーンショットは、UI テストで撮るようにしました。iPhone Duo を閉じた画面と iPhone 18 Pro の画面で、それぞれ 5 枚です。ステータスバーの時刻は 9:41 に固定し、見本の本は権利に問題のないものを使いました。手で撮り直さなくても、画面を変えたらテストを実行し直せば済みます。

年齢制限の質問票は 7 つの段階すべてが「なし」か「いいえ」で、4+ になりました。プライバシーポリシーとサポートのページは、公開のリポジトリの GitHub Pages に置き、問い合わせは GitHub の Issues で受けることにしました。

## 詰まったのは、アプリの外の手続きだった

時間がかかったのは、コードの外にある手続きでした。

Dropbox との連携では、最初に Dropbox の開発者向けの画面で作ったアプリが、個人のアカウントで作ったものではありませんでした。そこで、個人のアカウントで作り直しました。そのあと別のアカウントでつなぐと、「This app has reached its user limit」と出ました。開発中のアプリはつなげる人数に上限があり、追加の利用者を許可する設定 (最大 500 人) にすると、つなげるようになりました。本番の申請は、Dropbox の案内に従い、利用者が 50 人ほどになってから出すことにしました。

App Store Connect には、本人が答える申告や確認がいくつかありました。こうした項目は Claude in Chrome に入れてもらわず、私が内容を確かめて自分で答えました。

ビルドのアップロードでは、ふだんの開発に Xcode 27.3 beta を使い、App Store Connect に上げるときだけ正式版の Xcode を使うと決めました。輸出規制の対象になる暗号化を使っていないことは、Info.plist の `ITSAppUsesNonExemptEncryption` に `NO` と書いておきました。

## スピードを優先して丸ごと任せたのは、よい体験だった

今回は細部より速さを優先し、AI に丸ごと任せてみました。結果として、数日でストアに出すところまで進められ、よい体験になりました。この後は、使いながら細かいところを調整していくつもりです。英語への対応と、日本以外での配信も次の作業として残しています。

## まとめ

- 開発は 10 月 31 日から 11 月 4 日で 190 コミット、マージした PR は 42 本で、すべて Codex のレビューを通した
- Claude Code が実装と記録を、Claude in Chrome が App Store Connect への入力を受け持ち、私は選ぶこと、了承すること、本人にしかできない操作、最後の確認をした
- App のプライバシーやスクリーンショットは、コードと UI テストから決められた。詰まったのは、Dropbox のアカウントと利用者の上限、本人が答える申告のような、アプリの外の手続きだった
