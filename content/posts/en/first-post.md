Today I learned how to set up a Hugo blog for keeping track of my daily learnings. Hugo is a fast and flexible static site generator built in Go.

## Why Hugo?

- **Speed**: Hugo is incredibly fast at building sites
- **Flexibility**: Supports a wide range of content types
- **Simplicity**: Easy to set up and maintain
- **Markdown**: Write content in Markdown format

## Basic Hugo Commands

```bash
hugo new site mysite

hugo new posts/my-post.md

hugo server -D

hugo
```
